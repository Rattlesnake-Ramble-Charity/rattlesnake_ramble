# Rails 7.0 → 7.1 Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade the Rattlesnake Ramble app from Rails 7.0.10 to the latest 7.1.x release, with all tests passing and no new deprecation warnings.

**Architecture:** Standard Rails major-minor upgrade. Bump Gemfile constraint, run `bundle update`, run `bin/rails app:update` to surface new framework defaults, then flip `config.load_defaults` to `7.1` and chase down any deprecations or breakages.

**Tech Stack:** Rails 7.0.10 → 7.1.x, Ruby 3.2.10, PostgreSQL, RSpec, Sprockets/sass-rails (no Propshaft migration in this hop).

Tracking issue: [#237](https://github.com/Rattlesnake-Ramble-Charity/rattlesnake_ramble/issues/237)

### Task 5: Fix deprecations and failures

**Files:** Whatever surfaces from the suite run.

Common Rails 7.1 issues to check:
- `ActiveSupport::Deprecation` is now an instance — code calling class methods needs updating
- Stricter `ActiveRecord::Enum` syntax (positional vs keyword args)
- Default `belongs_to` is now optional-required-via-config; check `optional: true` flags
- New default for `config.action_view.button_to_generates_button_tag = true`
- `to_time` now returns local time by default
- `ActiveSupport::Cache` SHA256 by default

- [ ] **Step 1: Triage failures**

Run: `bundle exec rspec 2>&1 | tee /tmp/rspec-7-1.log`
Read failures and group by root cause.

- [ ] **Step 2: Fix each failure**

For each failing spec or deprecation warning, edit the underlying code (not the test) unless the test was asserting deprecated behavior. Commit fixes in logical chunks.

- [ ] **Step 3: Re-run until green**

Run: `bundle exec rspec`
Expected: 0 failures.
